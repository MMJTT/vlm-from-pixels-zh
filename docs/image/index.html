一张照片的旅程

SmolVLM-256M 怎样把一张照片变成一句话。所有数据都是模型在 Mac 上真实算出来的（导出脚本 tools/export_web_data.py），每一步都可以播放、拖动、点击。

1模型看到的照片

原图是 4:3 的，模型的视觉编码器只接受 512×512，于是照片被拉伸成正方形（第 02 章）。像素值再从 0~255 变成 −1~1。

2切块：1024 个 16×16 的小方块排成一队

ViT 把图片切成 32×32 个 patch，按"从左到右、从上到下"排成一条序列。每个 patch 是 16×16×3 = 768 个数，一个线性层（16×16 的卷积）把它变成一个 768 维向量，也就是一个 token（第 03 章）。

3视觉编码器：12 层里，图片变成了什么

拖动滑块逐层查看。PCA 着色：颜色相近 = 模型认为两个位置相似。切到注意力或相似度后，点击图片任意位置，看那个位置在这一层"看向哪里"、"和谁像"。

4连接器：1024 个 patch 压成 64 个 token

相邻 4×4 个 patch 的向量首尾拼接（16×768 = 12288 维），再用一个线性层投影到语言模型的 576 维（第 04 章）。一个 token 对应原图 64×64 像素。

5语言模型 30 层：图像 token 在哪一层变成了"词"？

Logit Lens：把每一层的输出直接解码成词（第 05 章）。中间层几乎都是 "and" 和空白，最后几层才出现 bowl、steak 这样的词。选一个概念词，看它的概率落在图片的哪里。

6逐词生成：每说一个词，它在看哪里？

贪心解码，一次一个词（第 06 章）。注意力：生成这个词时对 64 个图像 token 的注意力（30 层 × 9 头平均）。遮挡敏感度：挡住某一格后，这个词的概率下降多少，更能说明"这个词靠哪块图片说出来"。
