VLM 交互图解

视觉语言模型怎样看懂一张图片、一段视频？每一页都可以播放、拖动、点击，看清楚每一步发生了什么。页面里的数据都是小模型在 Mac 上真实算出来的；配套的 Jupyter 教程（中文逐行注释）在 GitHub 上。

基础原理

卷积是怎么算的

卷积核在图片上一格一格滑动，乘、加、得到输出像素。可以换卷积核、改步长，还能看到 ViT 的"切块"其实也是卷积。

注意力是怎么算的

5 个 token，从 Q、K、V 到打分、缩放、softmax、加权求和，一步一步算。可以切换因果掩码、调节温度。

完整旅程

一张照片的旅程

SmolVLM-256M：照片 → 1024 个 patch → 12 层视觉编码器 → 64 个 token → 30 层语言模型 → 逐词生成。点击照片任意位置看注意力，拖动滑块逐层看变化。

一段视频的旅程 ↗

Qwen2.5-Omni-3B：16 秒视频的画面和声音 → 3D patch 与 mel 频谱 → 每 2 秒交错排列 + TMRoPE 时间对齐 → 逐词生成时看向哪一秒。
